# App Icons

Place Fieldnotes app icons here for packaging:

- **icon.png** — 512×512 or 1024×1024 PNG (used for Linux and as source for others)
- **icon.ico** — Windows (multi-size: 16, 32, 48, 256)
- **icon.icns** — macOS (multi-size .icns bundle)

If these are missing, electron-builder will use the default Electron icon.  
You can generate .ico from icon.png using [electron-icon-builder](https://www.npmjs.com/package/electron-icon-builder) or an online converter.
